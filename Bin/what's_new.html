Hash Genify — version history

v3.0
  • Renamed the application from Quick Hash Genify to Hash Genify.
  • Added support for SHA-384 and SHA-512.
  • Added the new Checkifier tool for portable hash verification.
  • Added Export to Checkifier, allowing hash files to be exported with an embedded Checkifier executable — no separate checksum file needed.
  • Added Re-Generate Hash to regenerate hashes for selected files.
  • Added Set Root Path Depth to define the root/parent folder by moving up one or more directory levels.
  • Added drag-and-drop support for adding files from the same parent folder.
  • Redesigned the About dialog.
  • Fixed progress bar and percentage calculations for more accurate hash generation progress.
  • Improved folder drag-and-drop handling.
  • Improved hash file saving to automatically skip files that are missing or whose hashes cannot be generated.
  • Fixed various bugs and improved overall stability.
v2.0
  • Introduced a modern and clean interface for an intuitive user experience.
  • Updated the Main Menu and added a new Tasks menu.
  • Fixed various Popup Menu glitches.
  • Enhanced keyboard shortcuts for faster operation.
  • Added support for saving hashes separately for each file.
  • Improved the Save dialog with Save As support.
  • Added automatic file type detection based on the selected hash algorithm.
  • Added drag-and-drop support for files and folders.
  • Added support for CRC32, MD5, SHA-1, and SHA-256.
  • Added a File Size column for improved file information and overview.
  • Automatically sets generated hash files as read-only.
  • Improved ListView shortcuts for easier file management.
  • Added multiple path restrictions to keep file paths consistent.

Hash Checkify — version history

v3.0
  • Renamed the application from Quick Hash Checkify to Hash Checkify.
  • Added support for SHA-384 and SHA-512.
  • Boosted hash verification speed by up to 30x compared to old version.
  • Added file filtering with All, Genuine Only, Mismatched Only, and Missing Only options.
  • Removed support for the .md extension to avoid conflicts with Markdown files — MD5 checksum files now use .md5 only.
  • Improved automatic verification: any supported checksum file found in the application folder now starts verification automatically, regardless of its file name.
  • Fixed progress bar and percentage calculations for more accurate progress tracking.
  • Added command-line parameter support for opening checksum files directly.
  • Fixed various bugs and improved overall stability.
v2.0
  • Introduced a modern and clean interface for a smoother user experience.
  • Redesigned the Main Menu for faster navigation.
  • Added Scan Again and Stop Checking options for greater flexibility.
  • Improved the Popup Menu and fixed various interface glitches.
  • Enhanced keyboard shortcuts for faster operation.
  • Added support for CRC32, MD5, SHA-1, and SHA-256.
  • Improved hash calculation speed by up to 2× compared to version 1.0.
  • Added automatic verification when a checksum file is detected.
  • Added support for skipping invalid lines and comment lines.
  • Supported comment symbols: \, //, ;, #, and *.
